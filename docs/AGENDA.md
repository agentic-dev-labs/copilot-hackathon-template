# Five-day agenda

**Location:** Princeton, New Jersey  
**Dates:** Monday 26 October-Friday 30 October 2026

The goal is everyday AI capability, not turning every business participant into a developer.
Research, analyse, communicate, organise, automate, and build through short cycles of
**show -> try -> personalise -> verify -> share**. All five days use browser-based Codespaces
and its Linux terminal. The clock times, breaks, and core lab durations remain unchanged.

For a 30-minute teaching block, aim for 8 minutes showing, 17 trying, and 5 checking progress.
Repeat the cycle inside longer labs. Everyone has a default example and a choice of their own
question or output. Dependencies and prepared fallbacks are facilitator prework, not extra lab time.

Official starting points: [Copilot features](https://docs.github.com/en/copilot/get-started/features),
[VS Code agents](https://code.visualstudio.com/docs/agents/overview),
[customization comparison](https://docs.github.com/en/copilot/reference/customization-cheat-sheet),
and [current release notes](https://github.blog/changelog/label/copilot/).
Feature availability depends on client, model, licence, and policy; previews are not lab prerequisites.
Use the [coverage and official reference guide](REFERENCES.md) for topic-level links and short
optional tasks for every day. Tours show possibilities; the named labs are the required hands-on work.

**Finish:** a source-backed visual brief, one meaningful interactive feature that survives a
refresh in the same browser, reviewed work in GitHub, and the learner's deployed website.
Start with one report before extending to 2021-2025. Prepared extracts are labelled as prepared;
five completed downloads are a target, not permission to claim unobserved browser work.
The 11:45 presentation block is separate from Lab 01's 60-minute research/skill time-box.
