# Your Website

Create your own `index.html` here during Day 1. No finished learner website is provided.
Use HTML, CSS, and JavaScript, with intentional local images, fonts, and JSON data if needed.
Only reviewed public summaries or fictional data belong here. No PDFs, source-report extracts,
credentials, server code, or private notes. This folder is the **website** deployment target.

The morning presentation can become the afternoon website; a second project is not required.
Alternatively create a holiday planner, reading tracker, or another small tool using the same
folder. Keep `index.html` as the entry point and use relative links for local assets.

Run the preview command in Lab 02, then use **Ports > Open in Browser** in Codespaces.
The app keeps one browser's state in localStorage, not on the server or in a shared database.
Markdown planning notes are not served. Keep downloaded source material under ignored `research/`.

and [Lab 08](../labs/08-deploy/README.md).
