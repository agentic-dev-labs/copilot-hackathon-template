# Your Website

Create your own website here during Day 1. No finished learner website is provided.
Copilot builds one self-contained `index.html` with a local design kit, plus a small
`data/*.json` file of fictional sample entries. Nothing needs installing.
Only reviewed public summaries or fictional data belong here. No PDFs, source-report extracts,
credentials, server code, or private records. This folder is the **website** deployment target.

In Lab 01 run `/create-website` in Agent Chat and pick a Project Planner, Calendar, Ideas
Wall, or Weather page; the presenter demonstrates the Project Planner. It builds straight away
with your repository's name. The design kit, animated art and a local font are provided, not a
completed page. After checking, saving, and showing your first site, fast finishers can build
their own idea in `site/ideas/`; otherwise continue on Tuesday. Keep `index.html` as the entry point and use relative links for local
assets. Create `brief.md` during the separate first-note exercise to record your idea and checks.

Creation opens your first version in the **Website preview** panel beside Chat. There is no
server or port. Use `/start-website` if it is closed and `/stop-website` to close it; neither
changes your files. Ask for a colour or heading change and watch it appear by itself.
See [Lab 01](../labs/01-vscode-agent/README.md) if blocked. Keep improving through ordinary Chat.
The required finish is a checked interaction and saved work, not a public URL. The page
remembers your entries in this browser; that is not a shared database. Publishing is optional.
The preview and publication target do not serve Markdown planning notes, and the preview
loads only local files. Keep everything here fictional and intended for preview.
Keep downloaded source material under ignored `research/`.

Use fictional project names, not real company logos or official-looking corporate pages.

See [Lab 01](../labs/01-vscode-agent/README.md), [Lab 02](../labs/02-copilot-cli/README.md),
and [Lab 08](../labs/08-deploy/README.md), then [Tuesday's own-idea build](../docs/DAY-2-BUILD.md).
