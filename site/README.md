# Your Website

Create your own `index.html` here during Day 1. No finished learner website is provided.
Use HTML, CSS, and JavaScript, with intentional local images, fonts, and JSON data if needed.
Only reviewed public summaries or fictional data belong here. No PDFs, source-report extracts,
credentials, server code, or private notes. This folder is the **website** deployment target.

In Lab 01 run `/create-website` in Agent Chat. Choose a weekend, project, or budget planner;
the presenter demonstrates the weekend option. Answer one question at a time and approve the
small plan. Shared neutral CSS and a local licensed font are provided, not a completed page.
After checking, saving, and showing your first site, you may improve it or try an own-idea extension.
Tuesday protects more time for your own idea. Keep `index.html` as the entry point and use relative links for local
assets. Create `brief.md` during the separate first-note exercise to record your idea and checks.

Open your HTML file and run **Live Preview: Show Preview (Internal Browser)** from the Command
Palette. Keep Chat beside the embedded page. Save changes to refresh it. Keep forwarded ports
3000/3001 private; see [Lab 01](../labs/01-vscode-agent/README.md) for authentication and fallback steps.
Creation uses this preview after your approval and first build. Use `/start-website` if it
stops or closes, and `/stop-website` when you want to stop previewing. Neither recreates your
page or changes your files. Keep improving the chosen category through ordinary Chat.
The required finish is a checked interaction and saved work, not a public URL. Remembering
data with localStorage and publishing are optional extensions. Browser storage is not a shared database.
The Python preview and website publication target do not serve Markdown planning notes.
Live Preview serves from `site/`, so keep all its contents fictional and intended for preview.
Keep downloaded source material under ignored `research/`.

Use fictional project names, not real company logos or official-looking corporate pages.

See [Lab 01](../labs/01-vscode-agent/README.md), [Lab 02](../labs/02-copilot-cli/README.md),
and [Lab 08](../labs/08-deploy/README.md), then [Tuesday's own-idea build](../docs/DAY-2-BUILD.md).
