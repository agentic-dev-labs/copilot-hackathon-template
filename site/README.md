# Your Website

Create your own `index.html` here during Day 1. No finished learner website is provided.
Use HTML, CSS, and JavaScript, with intentional local images, fonts, and JSON data if needed.
Only reviewed public summaries or fictional data belong here. No PDFs, source-report extracts,
credentials, server code, or private notes. This folder is the **website** deployment target.

Monday starts with the shared fictional weekend planner. Personalise it after the guided steps;
Tuesday supports your own idea or continued work on the default. Keep `index.html` as the entry point and use relative links for local
assets. Create `brief.md` during the separate first-note exercise to record your idea and checks.

Run the preview command introduced in Lab 01, then use **Ports > Open in Browser** in Codespaces.
The required finish is a checked interaction and saved work, not a public URL. Remembering
data with localStorage and publishing are optional extensions. Browser storage is not a shared database.
Markdown planning notes are not served. Keep downloaded source material under ignored `research/`.

See [Lab 01](../labs/01-vscode-agent/README.md), [Lab 02](../labs/02-copilot-cli/README.md),
and [Lab 08](../labs/08-deploy/README.md), then [Tuesday's own-idea build](../docs/DAY-2-BUILD.md).
