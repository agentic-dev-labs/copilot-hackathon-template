# Optional Travel Practice

This retained fictional context is optional material for later agent/skill exploration,
not the required Day 1 exercise. [Lab 01](../../../labs/01-first-website/README.md) builds a first page
and [Lab 02](../../../labs/02-make-it-useful/README.md) adds a checked interaction. A fictional weekend
planner does not require this multi-agent travel workflow. For optional travel authoring, apply the role/skill patterns in the
[advanced agent-authoring reference](../post-workshop/advanced/agent-authoring-handoffs.md) to these inputs. Do not copy the facilitator's managed AttractionsAgent locally.

- [trip-brief.json](trip-brief.json): one fictional traveler, two hotel nights, dates, and budget.
- [practice-sources.md](practice-sources.md): fictional listings/events for repeatable checks.
- `output/`: your generated choices and itinerary, ignored by Git. Retain live/fixture labels.

Use permitted public pages for a separate live browser observation. Never submit a booking,
payment, passenger information, or a real employee's travel details. The fixture domains do
not resolve; they identify supplied text rather than sources you visited.

[Lab 08](../../../labs/08-save-and-share/README.md) optionally deploys the learner website; the vendor app is a separate
post-workshop example. Keep this optional research out of both images. No hosted travel agent is
provided and optional travel work does not change any required workshop finish condition.
